# HotelHub

Учебный веб-проект на **Django 6.0** — сервис поиска и бронирования отелей.
Реализован по паттерну **MVT (Model–View–Template)** с кастомной моделью
пользователя, сессиями и полноценным циклом бронирования.

## Возможности

- **Главная страница** (`core`) — витрина с популярными отелями, свободными
  номерами и статистикой.
- **Отели** (`hotels`) — список с поиском по городу и страница отеля с его номерами.
- **Номера** (`rooms`) — список с поиском по отелю/типу и страница номера.
- **Пользователи** (`users`) — регистрация, вход, выход и личный кабинет.
  Кастомная модель `User` (наследник `AbstractUser`) с полями `phone` и `avatar`.
- **Бронирования** (`bookings`) — создание брони на номер, расчёт стоимости
  (цена × число ночей), список своих броней и отмена. Доступно только
  авторизованным пользователям.
- **Админка** — управление всеми сущностями через стандартную панель Django.

## Архитектура

```
config/      — настройки проекта, корневая маршрутизация
core/        — главная страница (объединяет данные других приложений)
users/       — кастомный пользователь, аутентификация, профиль
hotels/      — отели
rooms/       — номера (FK на отель)
bookings/    — бронирования (FK на пользователя и номер)
templates/   — глобальные шаблоны (base.html, навигация, футер)
static/      — глобальная дизайн-система (base.css)
```

Каждое приложение изолировано: свои `models`, `views`, `urls`, `templates`,
пространство имён URL (`users:login`, `hotels:hotel_detail` и т.д.).

## Запуск

```bash
# 1. Виртуальное окружение
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Зависимости
pip install -r requirements.txt

# 3. Миграции
python manage.py migrate

# 4. Демо-данные (отели, номера, пользователи, брони)
python manage.py seed

# 5. Запуск
python manage.py runserver
```

Откройте http://127.0.0.1:8000/

## Тесты

```bash
python manage.py test
```

Покрыты: кастомная модель пользователя, регистрация с авто-входом, защита
профиля, расчёт стоимости брони, проверка прав и валидация дат.
